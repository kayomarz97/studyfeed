## Plain-language

Build the playable deck: a flashcard for each solid fact, extra multiple-choice questions where the
curated bank is thin, short "reel" fact-cards, a few paragraph "blobs" with a quiz-back, and
concept-link questions. Every generated item must trace to a real source (grounded) or it's thrown out.
We generate with **Claude Code helper agents** (your plan) instead of the paid API — so it costs no API
money, but it means many helper runs, so we **pilot one small batch first**, measure, then scale.

## The execution problem (why pilot first)

Standard ≈ **44k generated items**. Through CC subagents at ~200 items/run that's **~235 subagent runs**
across several hours and heavy CC-plan usage — and at C4 the user chose the API precisely to spare the CC
cap. So: **generate highest-importance first**, in **resumable checkpointed chunks**, and run a **1-chunk
pilot** to measure real quality + CC burn before committing to the full fan-out. If the extrapolation is
ugly, options are (a) trim volume, (b) opt into a Workflow to automate the fan-out, (c) proceed in waves.

## Pipeline (`generate.py` — orchestration scaffolding; generation is the subagents)

1. `prep(asset)` → chunk the scored inputs into `work/gen_input/<asset>/NNNN.jsonl` **importance desc**,
   write `work/gen_manifest.json` (per-chunk status pending/done → **resumable + idempotent**, §1).
2. For each pending chunk: spawn the matching `gen-*` subagent (CC usage) → writes
   `work/gen_output/<asset>/NNNN.jsonl`. Highest-importance chunks first.
3. `validate(asset)` — deterministic grounding gate: ref resolves to a real atom/edge; back/answer is
   non-empty and shares salient tokens with the cited atom; MCQ has exactly one key + 4 distractors;
   reject + log rate (evidence floor). Ungrounded → quarantine, never shipped.
4. `collect(asset)` → `work/gen_<asset>.jsonl`; feed_items assembled at C13 packaging.

## Grounding & determinism
- Generated prose is NOT required to be byte-identical (only importance scores are, §reproducible).
- Generate **once**, store; packaging upserts incrementally (idempotent) so a rebuild doesn't churn.
- Every item carries its source ref; `grounding-validator` / deterministic check enforces the evidence floor.
